# ============================================================
# WINDOWS SETUP — READ BEFORE RUNNING pip install
# ============================================================
#
# 1) TESSERACT BINARY (required, not installed by pip):
#    pytesseract/passporteye only call the `tesseract` executable — they
#    don't ship it. Without this, MRZ passport reads silently fall through
#    to the EasyOCR fallback every time (no crash, just no checksum path).
#      -> Install: https://github.com/UB-Mannheim/tesseract/wiki
#      -> Add its install folder (contains tesseract.exe) to your PATH
#      -> Verify with: tesseract --version
#
# 2) PYTHON VERSION:
#    Use Python 3.10 or 3.11. TensorFlow 2.16 / DeepFace can be flaky on
#    3.12 on Windows. Check with: python --version
#
# 3) DEEPFACE / TENSORFLOW MODEL WEIGHTS:
#    First call to DeepFace.verify() auto-downloads VGG-Face weights
#    (~500MB) from the internet. Do this once, BEFORE your demo:
#      python -c "from deepface import DeepFace; DeepFace.build_model('VGG-Face')"
#
# 4) EASYOCR MODEL WEIGHTS:
#    Also auto-downloads (~100MB) on first use. Warm up in advance:
#      python -c "import easyocr; easyocr.Reader(['en'], gpu=False)"
#
# ============================================================
